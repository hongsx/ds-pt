# ds-pt

电商平台

This repository is for a multi-language e-commerce starter project (Next.js frontend + NestJS backend + MySQL + Redis).

仓库将包含一个名为 `starter/nextjs-nestjs` 的分支，里面有前端（Next.js）、后端（NestJS）、数据库和缓存（MySQL + Redis）的开发环境示例（含 docker-compose）、以及中文/英文双语的使用说明。

当前默认分支包含最小的仓库说明与忽略规则。请查看 `starter/nextjs-nestjs` 分支以获取 Starter 项目骨架（将在分支创建后提交）。
