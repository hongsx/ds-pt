# Starter: Next.js + NestJS + Prisma + MySQL + Redis

This branch contains a starter skeleton for a multi-language e-commerce project.

Structure:
- frontend/  — Next.js (TypeScript) with i18n
- backend/   — NestJS (TypeScript) with Prisma (MySQL) and Redis support
- docker-compose.yml — local dev with MySQL and Redis

See README-starter.md in the repository root for usage and instructions.
